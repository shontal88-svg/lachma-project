# פרויקט WhatsApp — לחמא · לוח משימות

לוח ניהול משימות בזמן אמת לצוות הפרויקט (שון · ליז · שרון).

## איך משתמשים

1. פותחים את הלינק: https://shontal88-svg.github.io/lachma-project/
2. בוחרים את השם שלכם מהבורר "משתמש:" בראש הדף.
3. מסמנים משימות, פותחים תתי-משימות, כותבים הערות.
4. השינויים מסונכרנים אוטומטית בענן ומופיעים אצל כל הצוות תוך כמה שניות.

לכל משימה מוצג מי עדכן אותה לאחרונה ("עודכן ע״י ליז · לפני 3 דק׳"). אינדיקטור עליון בצד שמאל מציג את מצב הסנכרון:

- 🟢 **מסונכרן** — הכל בענן ועדכני.
- 🟡 **שומר / טוען** — פעולה ברגע זה.
- 🔴 **לא מחובר** — אין רשת או שירות הענן זמני נופל. הסימונים נשמרים לוקאלית ויעלו אוטומטית כשהחיבור חוזר.
- ⚫ **לוקאלי בלבד** — לא הוגדרו מפתחות jsonbin. ראה למטה.

## הגדרת ענן (חד-פעמי)

הקובץ `index.html` משתמש ב-[jsonbin.io](https://jsonbin.io) כענן משותף. כדי להפעיל את הסנכרון יש להגדיר שני קבועים בראש ה-`<script>`:

```js
const JSONBIN_BIN_ID = '...';
const JSONBIN_ACCESS_KEY = '...';
```

הצעדים ליצירת בין ו-Access Key:

1. נרשמים חינם ב-<https://jsonbin.io/login>.
2. ב-Dashboard לוחצים **CREATE BIN** ומדביקים `{ "tasks": {} }`. שומרים.
3. מעתיקים את ה-**Bin ID** שמופיע בכותרת.
4. בתפריט **API Keys → Access Keys** יוצרים מפתח חדש: `lachma-readwrite`, עם הרשאות Read + Update לבין הזה.
5. ממלאים את שני הערכים בקובץ ועושים commit + push.

## תזכורות

- מגבלת jsonbin בחינם: 10K בקשות/חודש. עם שימוש מתון לצוות של 3 אנשים זה מספיק; אם תחרגו, הגדילו את `POLL_INTERVAL_MS` ל-15000.
- כפתור "איפוס" מוחק את כל הנתונים — **לכל הצוות**. יש אישור.
- כפתור "ייצוא סטטוס" מעתיק טקסט מסודר ללוח, מוכן להדבקה ב-WhatsApp.
